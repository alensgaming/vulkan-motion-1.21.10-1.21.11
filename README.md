# ✨ Motion Blur — Smooth Cinematic Blur for Vulkan & Fabric

Bring smooth cinematic motion blur to Minecraft with full Vulkan, Sodium, and Vanilla compatibility.  
Enjoy fluid movement, customizable blur, and a simple in-game configuration system.

---

## 🌟 Features

- 🎥 Smooth motion blur effects  
- ⚡ Vulkan optimized rendering support  
- 🧩 Compatible with Sodium & Vanilla  
- 🎛️ Easy GUI + command configuration  
- 🪶 Lightweight client-side mod  
- 🔧 Fully customizable settings  

---

## 📦 Compatibility

🎮 Minecraft: 1.21.10+  
🖥️ VulkanMod: 0.5.7  
🧱 Loader: Fabric  
📍 Side: Client Only  

---

## ✅ Requirements

- ☕ Java 21 or newer  
- 🧵 Fabric Loader 0.16.0+ → https://fabricmc.net/use/  
- 🛠️ Fabric API → https://modrinth.com/mod/fabric-api  
- 🎮 Minecraft 1.21.10  

---

### ⭐ Optional

- 📋 Mod Menu → https://modrinth.com/mod/modmenu  
  (Adds config screen inside Mods menu)

---

## 🚀 Installation

1. Install **Fabric Loader** for Minecraft 1.21.10  
2. Place **Fabric API** into your `mods/` folder  
3. Drop the **Motion Blur mod jar** into `mods/`  
4. (Optional) Install **Mod Menu** for easier settings access  
5. Launch Minecraft 🎮  

---

## ⚙️ Configuration

- 🎚️ Adjust blur strength  
- 🖱️ Simple GUI menu  
- 💬 Command support  
- ⚡ Vulkan-friendly rendering system
